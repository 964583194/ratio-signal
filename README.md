# 指数定投信号看板

一个静态网页，八个页签：总览、创业板轮动、科创板轮动、红利打分、中证A500、沪深300、纳指100、黄金。

- **创业板 / 科创板轮动（平衡版，见 `scripts/plan.py`）**：信号值 = 成长端 ÷ 红利低波100。阈值每年 1 月、7 月按过去 10 年分位重算（中位数以下每周买、25% 加大、13% 翻倍；89% / 94% / 98% 三档卖出）；买入每周集中一次、连续 3 天确认；卖出用趋势确认（跌破信号 20 日均线）、目标止盈（盈利 50% / 100%）、红利打分联动；闲钱和卖出的钱放红利；极低值分 3 批把红利转回。
- **中证A500 / 沪深300**：便宜指数决定倍数；没买完的钱放红利，偏贵区间目标止盈。
- **纳指100**：照常定投，回撤只作参考，看 ETF 溢价率决定场内还是场外。
- **黄金（518880）**：每周定投，比年线高 25% 以上暂停，回撤 15% 以上 2 倍。
- **红利打分**：红利低波100 每日定投打分。
- **建议比例**：创业板 25%、科创板 15%、纳指 20%、红利 15%、黄金 15%、沪深300 5%、A500 5%。

GitHub Actions 每个交易日自动拉取收盘价并更新数据，网页通过 GitHub Pages 免费托管。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 网页本体，读取 `data/ratio.json` 显示 |
| `scripts/update.py` | 拉取两个指数日线，计算比值、统计和回测，写入 `data/ratio.json` |
| `.github/workflows/update.yml` | 定时任务：工作日 17:30、21:07，周五 08:13（发周报）、周六 09:13（北京时间）自动运行 |
| `scripts/dividend.py` | 红利低波100 打分：PE、全收益指数推算股息率、十年国债、RSI/布林，写入 `data/dividend.json` |
| `scripts/sources.py` | 所有取数接口、备用顺序、增量更新与缓存 |
| `scripts/value.py` | 中证A500、沪深300、纳指100、黄金 指标与回测 |
| `scripts/plan.py` | 创业板 / 科创板轮动平衡版规则与回测 |
| `scripts/notify.py` | 信号变化提醒、周五周报（GitHub 通知邮件） |
| `data/*.json` | 页面读取的结果文件，Actions 自动生成 |
| `data/raw/*.csv` | 原始数据缓存，每天一行 |
| `data/state.json` | 上次提醒时的信号状态 |

## 部署步骤

1. 在 GitHub 新建一个仓库（公开仓库才能免费用 Pages），把本文件夹里的所有文件上传，保持目录结构不变。
   - 网页上传时注意 `.github` 是隐藏文件夹，建议用 GitHub Desktop 或 `git push` 上传，确保它被包含。
2. 打开仓库 **Settings → Actions → General**，在 Workflow permissions 选 **Read and write permissions**，保存。
3. 打开 **Actions** 页，选“更新比值数据”，点 **Run workflow** 手动跑一次，生成 `data/ratio.json`。
4. 打开 **Settings → Pages**，Source 选 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
5. 一两分钟后访问 `https://你的用户名.github.io/仓库名/` 即可。之后每个交易日会自动更新。

## 数据来源与备用接口

每项数据都配了多个接口，按顺序尝试，第一个通过检查的就用。

- **增量更新**：缓存（`data/raw/*.csv`）已有历史时，只向接口要最近约 60 天的数据，请求次数和数据量都很小；没有缓存才拉全量。
- **核对**：新数据和缓存重叠的日期必须数值一致，对不上的接口会被跳过，防止换了口径的数据混进来。
- **兜底**：所有接口都失败时，用缓存继续计算。
- **不重复计算**：数据没有变化（周末、节假日）时跳过计算、不提交。

| 数据 | 接口（按优先顺序） |
|---|---|
| 创业板50 | 东方财富 → 国证指数官网 → 腾讯 → 新浪（近1000天） |
| 红利低波100 收盘 / 全收益 | 中证指数官网 → 东方财富 |
| 红利低波100 市盈率 | 中证指数官网（+ 缓存） |
| 科创50 | 东方财富 → 中证指数官网 → 腾讯 → 新浪 |
| 中证A500 | 东方财富 → 中证指数官网 → 新浪 → 腾讯 |
| 沪深300 / A500 市盈率 | 中证指数官网（+ 缓存） |
| 中国十年国债 | 东方财富（+ 缓存） |
| 美国十年国债 | 东方财富 → 美国财政部 → 美联储 FRED |
| 纳指100 | 腾讯 → 新浪 → 东方财富 → 纳斯达克官网 → 美联储 FRED |
| 黄金ETF 518880 | 东方财富 → 腾讯 → 新浪 |
| 纳指ETF 513100 价格 / 净值 | 东方财富 / 天天基金 → 腾讯 / 东方财富 → 新浪 |

每次运行会写 `data/health.json`，页面底部显示状态。任何一项超过 12 天没更新，Actions 任务会失败，GitHub 自动发邮件提醒。

## 信号提醒与周报

`scripts/notify.py` 在仓库里新建 Issue 并 @ 仓库主人，GitHub 会把它发到主人的通知邮箱：

- 信号有变化时（比值跨线、卖出档、红利换档、A500 换区间、纳指回撤档 / 年线 / 溢价率、数据源异常）当天提醒；
- 每周五早上发一封周报（A股按周四收盘、纳指按美股周四收盘），汇总各页签的现状和本周操作；
- 同类旧提醒会自动关闭，只保留最新一条，邮件不受影响。

收不到邮件时检查：GitHub → Settings → Notifications，确认 Email 通知已开启、通知邮箱正确。
在 Actions 页手动运行时勾选“发送周报邮件”可以立即发一封周报。
手动体检所有接口：`cd scripts && python sources.py`

## 旧版说明：数据来源

- 创业板50：东方财富日K接口
- 红利低波100：中证指数官网（失败时改用东方财富）

GitHub 的服务器在海外，偶尔会被这些接口拒绝。如果 Actions 运行失败，可以：

- 过一会儿在 Actions 页手动重跑；
- 或者在自己电脑上运行（国内网络更稳定），再把生成的 `data/ratio.json` 推到仓库：

```bash
python scripts/update.py
```

也可以用自己导出的数据（两列 CSV：日期,收盘价）：

```bash
CYB_CSV=创业板50.csv HL_CSV=红利低波100.csv python scripts/update.py
```

## 参数

轮动规则参数在 `scripts/plan.py` 顶部（分位、窗口、定投额）；A500 / 沪深300 / 黄金在 `scripts/value.py`；
`scripts/update.py` 里的 `LO` / `HI` / `SELLS` 只用于旧版固定线的回测对比。
